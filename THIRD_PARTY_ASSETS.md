# Third-party asset provenance

The MIT license at the repository root applies to the project code as applicable; it does not replace the licenses of supplied third-party packs, models, textures, artwork or audio.

Original archives, author readmes, editable sources and supplied license files are preserved in the `originals` release package. `assets/context/provided-files-manifest.json`, `assets/context/archive-members.json` and `assets/context/PACK_COVERAGE.md` identify the exact supplied files and their provenance. Refer to those original terms when reusing or redistributing any pack. The uploader explicitly requested that this repository and its asset release remain public.
